# Getting help

s7video is pre-alpha and maintained by volunteers. There is no paid support, and answers may take a
few days.

| You want to…                     | Go to                                                                                                                |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------- |
| Report a bug                     | A [bug report](https://github.com/ideanavigator/s7video/issues/new?template=bug.yml)                                 |
| Suggest a feature or improvement | A [feature request](https://github.com/ideanavigator/s7video/issues/new?template=feature.yml)                        |
| Ask a question about using it    | Search [existing issues](https://github.com/ideanavigator/s7video/issues), then open a feature request or bug report |
| Set up a development build       | The [README](README.md#quick-start-development) and the [development runbook](docs/operations/development.md)        |
| Contribute                       | [CONTRIBUTING.md](CONTRIBUTING.md)                                                                                   |
| Report a security problem        | [SECURITY.md](SECURITY.md); never a public issue                                                                     |
| Report a conduct problem         | The contact in the [Code of Conduct](CODE_OF_CONDUCT.md)                                                             |

Before asking, check that you are on the latest `main` and that you have at least one coding-agent CLI
(for example Claude Code or Codex) installed and signed in.

When you post logs or screenshots, remove API keys, file paths you consider private, and any footage or
audio that is not yours. Never attach client footage.

## Problems with a coding agent

s7video runs the agent CLIs you have installed with your own accounts. Problems inside those tools,
such as sign-in, billing or model behaviour, belong with their makers, for example
[Claude Code](https://github.com/anthropics/claude-code/issues) or
[Codex](https://github.com/openai/codex/issues).
