### MIT licence, attribution, REUSE headers and licence check

- **Ticket:** S7V-004
- **Section:** Added
- **What:** The licence names both T3 Tools Inc. and the s7video contributors, a new `NOTICE` credits T3 Code and the proprietary Claude Agent SDK, and **Settings > About > Open source licenses** now starts with T3 Code and shows Chromium's notice. Every file in the repository has machine-readable copyright and licence information (`pnpm reuse:lint`), and `pnpm licenses:check` fails when any installed package has a missing licence or one outside our allowlist.
- **Why:** Anyone using or contributing to s7video can see exactly what is inside and under which terms, and a dependency with the wrong licence cannot slip in unnoticed.
