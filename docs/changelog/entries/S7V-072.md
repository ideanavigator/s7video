### The assistant carries only video tools in video projects

- **Ticket:** S7V-072
- **Section:** Changed
- **What:** In a video project the assistant is offered only its video-editing tools, and none of the coding, pull-request, browser or device tools it inherited. Each reply sends about 95% less tool setup text. Other projects are unchanged.
- **Why:** Creators never use the coding tools. Leaving them out makes replies cheaper and keeps room for this sprint's new editing tools.
