### Clear message when a dropped clip can't be added

- **Ticket:** S7V-071
- **Section:** Fixed
- **What:** A clip dropped into the chat that can't be added to Assets now shows why, with Retry, instead of being attached silently; a sound that can't be added stays attached, and the message says so. The engine no longer writes Python bytecode into the app's folders.
- **Why:** Clips looked "hidden": they never reached Assets and the Editor never opened, with no message. In development the bytecode files restarted the server mid-import.
