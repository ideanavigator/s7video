### Versions in chat

- **Ticket:** S7V-070
- **Section:** Added
- **What:** Ask the assistant about your versions by number or name, or say "make v12 current" or "go back to the first cut": it brings that version back as the newest one, and nothing is lost. Picking a version with @ in the chat box comes later.
- **Why:** Creators edit by chat and want to refer to and return to earlier cuts there too.
