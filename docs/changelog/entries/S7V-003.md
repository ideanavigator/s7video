### Own name, data folder and settings file

- **Ticket:** S7V-003
- **Section:** Changed
- **What:** The app is called s7video everywhere and keeps its data in `~/.s7video`. The name, theme, links, update and analytics endpoints all come from `s7video.config.ts`. It can be installed next to T3 Code without either app touching the other's data, CLI or links. SSH, device-host and WSL environments are turned off for now.
- **Why:** s7video must never read or change T3 Code's data, and a fork should be able to rename and re-theme it from one file.
