### Dev desktop apps from different worktrees run side by side

- **Ticket:** S7V-073
- **Section:** Fixed
- **What:** For developers: a dev desktop app started from a linked git worktree now keeps its own Electron profile inside that worktree's dev home, so it no longer hands off to, or focuses, another checkout's app. The main checkout keeps its `s7video-dev` profile.
- **Why:** A second checkout's dev app could not take the shared single-instance lock and kept relaunching.
