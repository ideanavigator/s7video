### Usage data off by default

- **Ticket:** S7V-013
- **Section:** Changed
- **What:** s7video records and sends no usage data unless you turn on **Share anonymous usage data** in the new **Settings > Privacy** page or set `S7VIDEO_TELEMETRY_ENABLED=true`. The switch appears only in builds that name a usage-data destination; the open-source build names none, so it shows just the privacy policy link. Upstream's `T3CODE_TELEMETRY_*` and `T3CODE_POSTHOG_*` variables are ignored, and `pnpm brand:check` fails if T3's analytics host or a PostHog key appears anywhere in the repo.
- **Why:** Nothing you do in s7video should be reported to anyone, least of all another company, unless you choose it.
