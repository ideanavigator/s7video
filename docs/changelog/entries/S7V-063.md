### Honest reply when an undo changes nothing

- **Ticket:** S7V-063
- **Section:** Fixed
- **What:** When an undo or redo makes no visible difference (such as going back past adding a clip, which stays in Assets), the agent says so and tells you whether there is more to undo.
- **Why:** The agent said "Undone" for a step that changed nothing, so users spent undos without knowing why.
