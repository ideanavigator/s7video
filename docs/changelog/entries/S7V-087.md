### Looking at an older version no longer changes your edit

- **Ticket:** S7V-087
- **Section:** Fixed
- **What:** While you look at an older version, the timeline only lets you look: dragging, trimming, splitting or deleting a clip no longer changes your main edit, and a click on the timeline takes you back to it. Messages about versions now say "main" like the Versions tab.
- **Why:** The timeline still edited the main edit while the player showed the older version, so you could change your edit without seeing it.
